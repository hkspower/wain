# Press kit — Gulf Road Nights

Hero captures from the running game, straight out of the renderer with no
retouching, for the Steam store page and press use.

| Shot | What it shows |
| --- | --- |
| `efreet-rx-kai-front.png` | The Efreet RX Kai at first light — splitter, canards, vented hood |
| `efreet-rx-kai-side.png` | Profile: swan-neck wing, side skirts, bronze six-spokes |
| `efreet-rx-kai-rear.png` | Rear three-quarter under braking — wing endplates, diffuser, tail lamps lit |

All three are 1280×720 captures of the dawn sky mode. Regenerate them with
`/tmp/smoke/kaishots.mjs` against a running dev server.

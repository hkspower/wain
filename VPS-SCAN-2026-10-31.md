## Who serves www.sporta.com.kw
`apache-sporta-1` (image `apache-sporta`, Apache 2.4 + PHP, healthy). It is running in
the `apache` project, but the `apache` compose file **has no `sporta` service** — the
container is an orphan from an earlier version of that file. A `docker compose up
--remove-orphans` or an "Update project" on `apache` could stop the live shop.

The stopped `sporta` project is the intended home: compose mounts `./site` as the web
root, `./private/*-config.php` read-only over api/knet/pay config, DB secrets as files,
joins `sporta-db_default`, and carries the Traefik router for `sporta.com.kw` +
`www.sporta.com.kw`. It fails because its image was never built.

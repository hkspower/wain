## This is a sample, and it is deliberately NOT in public/voice/

It does not match the library's own spec in two ways, and both are audible or
measurable rather than cosmetic:

  bitrate   128 kbps here; gen-voice.mjs asks for mp3_44100_64, i.e. 64. This
            file is 123KB and would be ~53KB at the specified rate. Across 324
            clips that is roughly 6MB against 3MB, shipped in the static export
            to phones in Kuwait.

  settings  gen-voice.mjs sends stability 0.35 and similarity_boost 0.8 for شوق.
            The connector's speech tool takes prompt, model, voice and a count —
            there is no parameter for either, so this render used the defaults.

The second one is the one that matters. docs/voice.md holds a three-way table
because a recorded clip and a live sentence from the n8n TTS bridge are heard
inside a single utterance; the bridge had already drifted once to a different
woman entirely and nothing broke, which is why it went unnoticed. A library
generated at default settings would drift the same way, quietly, in the same
place.

So: use this to HEAR her and to confirm the voice is right. Generate the library
with the script.

# Per-place link previews

One 1200×630 card per place, generated by `scripts/gen-og.mjs` (`npm run og`).

Committed on purpose: a normal build and deploy never regenerates them, so the
project does not depend on Playwright. Rerun `npm run og` only after changing a
place's name, area, rating or art — it needs the built site served locally, and
`npm i -D playwright` first.

Two engines, each doing what it is good at. **Chromium lays out the type**,
because sharp cannot shape Arabic here — there are no Arabic system fonts and
it renders the letters reversed and unjoined. **sharp does the raster finish**:
vignette, grain and a levels nudge, then the JPEG encode.

These are deliberately NOT in the service worker precache. They are link
previews, fetched by WhatsApp and X and never by a visitor, so precaching them
would add ~660KB to an offline install for images nobody on the site ever sees.

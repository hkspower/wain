# موقع موصول — MAWSOOL

موقع تعريفي عربي (RTL) لشركة توصيل الطلبات بالسيارات في الكويت، مبني بهوية الشعار المرفق نفسها.

## التشغيل

الموقع ثابت بالكامل (HTML + CSS + JavaScript) بلا أي خطوة بناء أو اعتماديات:

```bash
cd website
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

أو افتح `index.html` مباشرة في المتصفح.

## الملفات

```
website/
├── index.html   # كل أقسام الصفحة
├── styles.css   # الأنماط ومتغيرات الهوية
├── script.js    # القائمة، التبويبات، التتبع، التحقق من النماذج
└── assets/      # الشعار وأيقوناته (مستخرجة من ملف الشعار الأصلي)
```

## ألوان الهوية

مأخوذة مباشرة من ملف الشعار `logo_mawsool.pdf`:

| اللون | القيمة | الاستخدام |
|---|---|---|
| الأزرق المخضر | `#1A8E9B` | اللون الأساسي — الأزرار، العناوين، الخلفيات الداكنة |
| البرتقالي | `#F69625` | اللون المكمّل — التمييز، أزرار الدعوة للإجراء، الأرقام |
| درجات مساندة | `#0f6b76` · `#22a7b4` · `#dff2f4` · `#fff1de` | تدرّجات وخلفيات وحدود |

جميع الدرجات معرّفة كمتغيرات CSS في أعلى `styles.css` تحت `:root`.

## الشعار

استُخرج الشعار من ملف الـ PDF الأصلي وحُوِّل إلى صور PNG بخلفية شفافة:

| الملف | الوصف |
|---|---|
| `assets/logo-mawsool.png` | الشعار الكامل بألوانه الأصلية |
| `assets/logo-mawsool-light.png` | نسخة فاتحة للخلفيات الداكنة (النص أبيض والبرتقالي كما هو) |
| `assets/mawsool-mark.png` | الأيقونة (الدبوس) فقط |
| `assets/mawsool-mark-light.png` | الأيقونة بنسخة فاتحة |
| `assets/mawsool-mark-512.png` | أيقونة مربّعة ٥١٢×٥١٢ |
| `assets/favicon.ico` · `assets/apple-touch-icon.png` | أيقونات المتصفح والأجهزة |

## أقسام الصفحة

الواجهة، شريط الأرقام، الخدمات، آلية العمل، الأسطول، لماذا موصول، مناطق التغطية (تبويبات تفاعلية للمحافظات الست)، الأسعار، تتبع الطلب، آراء العملاء، نموذج الطلب، الأسئلة الشائعة، الفوتر.

## ملاحظات قبل النشر

المحتوى التجاري في الموقع نموذجي ويحتاج استبداله ببيانات الشركة الحقيقية:

- **بيانات التواصل**: `+965 2222 0000`، واتساب `+965 9000 0000`، `hello@mawsool.com.kw`، والعنوان — كلها قيم مؤقتة (في `index.html` والفوتر ونموذج الطلب).
- **الأسعار والأرقام**: باقات الأسعار وإحصاءات شريط الأرقام وأوقات التوصيل لكل محافظة قيم تقديرية.
- **آراء العملاء**: أسماء وشهادات تجريبية.
- **نموذج الطلب والتتبع**: يعملان في المتصفح فقط (تحقق من المدخلات ورسالة نجاح ورقم طلب عشوائي) — لا يوجد خادم خلفهما. لربطهما بنظام حقيقي، استبدل معالج `submit` في `script.js` باستدعاء واجهة برمجية.
- **روابط التواصل الاجتماعي** في الفوتر مؤقتة (`#`).
- **الخطوط**: يُحمَّل خطا Cairo وTajawal من Google Fonts؛ عند تعذّر الوصول للشبكة يرجع الموقع تلقائيًا إلى خطوط النظام.

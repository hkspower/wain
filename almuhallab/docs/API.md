# `window.Nokhatha` — الواجهة البرمجية للنوخذة

طريق موثّق للدخول إلى سجلاتك والخروج منها: لصفحة، أو سكربت، أو نظام آخر عندك.
**بلا خادم، وبلا نسخة ثانية من أي شيء.**

تعمل في `nizam.html` بعد تحميل الصفحة.

```js
Nokhatha.version              // "1.0.0"
```

---

## لماذا بلا خادم

النوخذة تَعِد أن **سجلاتك لا تغادر جهازك**، وأنها **تعمل بلا إنترنت**. وواجهة
تُرسل السجلات إلى خادم تنقض الوعدين معاً. فهذه الواجهة تعمل في متصفّحك على
تخزينك أنت — وهي غلاف على النواة الموجودة أصلاً، لا نواة موازية:

- كل **قراءة** تمرّ بالتنقية نفسها التي تمرّ بها الشاشات، فلا تُسلّمك الواجهة
  سجلاً ترفضه الشاشة.
- كل **كتابة** تمرّ بـ`wr()` نفسها، فلا تُبلّغ بنجاح لم يقع. (وهذا خطأ وقع
  فعلاً هنا من قبل: الحفظ يفشل والرسالة تقول «تمّت الإضافة».)

## القراءة

```js
Nokhatha.holdings()    // [{ticker, name, qty, cost, price}, …]
Nokhatha.orders()      // [{id, customer, phone, address, items, amount,
                       //   courier, status, createdAt}, …]
Nokhatha.couriers()    // [{name, phone}, …]
Nokhatha.reports()     // تقارير XBRL المحفوظة
Nokhatha.statuses()    // ["جديد","قيد التحضير","في الطريق","تم التسليم","ملغي"]
Nokhatha.totals()      // الأرقام المشتقّة — من المكان الوحيد الذي تُعرَّف فيه
```

**القراءة تعطيك نسخة، لا المخزن.** عدّل ما أُعطيت فلن يتغيّر شيء عند غيرك:
المخزن لا يتغيّر إلا بدوالّ الكتابة، وهي تتحقّق ممّا يصلها.

**ولا تنسيق هنا.** الواجهة تُرجع **أرقاماً**، والتنسيق شأن الشاشة التي تطبعها.
واجهة تُرجع `"1,240.500"` تُجبر كل مستدعٍ على تحليلها من جديد، وتطبع أرقاماً
هنديّة على جهازٍ لغته عربية.

```js
Nokhatha.totals()
// { portfolio: {count, cost, value, pl, pct},
//   delivery:  {total, active, delivered, cancelled, revenue},
//   nonCurrentAssets, revenue, netWorth }
```

## الكتابة

كل دالّة كتابة تُرجع `{ok: true, value}` أو `{ok: false, error}` — **افحص
`ok` دائماً**؛ الفشل ليس استثناءً يُرمى، بل جواب.

```js
Nokhatha.addHolding({ticker: "ZAIN", name: "زين", qty: 100, cost: 500, price: 620})
Nokhatha.removeHolding("ZAIN")

Nokhatha.addOrder({id: "1042", customer: "أحمد", amount: 78.5, status: 3})
Nokhatha.setOrderStatus("1042", 3)      // 0..4، انظر statuses()

Nokhatha.clear("safi")                   // safi · delivery · couriers · reports
```

### ما تردّه الواجهة، ولماذا

| المدخل | الجواب |
|---|---|
| رمز سهم مكرّر | `هذا الرمز مضاف بالفعل: ZAIN` |
| بلا رمز | `رمز السهم مطلوب` |
| `qty: -50` أو `0` أو غائبة | `الكمية يجب أن تكون سهماً واحداً فأكثر` |
| رقم طلب مكرّر | `رقم الطلب مستعمل: 1042` |
| حالة خارج المدى | `حالة غير معروفة — استعمل 0..4` |
| طلب غير موجود | `لا يوجد طلب بالرقم 9999` |
| وحدة غير معروفة | `وحدة غير معروفة: nope` |
| التخزين ممتلئ | `تعذّر الحفظ على هذا الجهاز…` |

الكمية السالبة **تُرفض ولا تُقصّ إلى صفر**. القصّ كان يخزّن «سهماً بلا أسهم»
ويُبلّغ بالنجاح — كشفه الاختبار: `addHolding({ticker:'NBK', qty:-50})` أجاب
`ok`. كميّةٌ لا يمكن أن يقصدها المستدعي **خطأٌ منه، لا صفر**.

## التصدير والاستيراد

```js
const backup = Nokhatha.export();
// {version, exportedAt, safi, orders, couriers, reports}

Nokhatha.import(backup);                 // يستبدل
Nokhatha.import(backup, {merge: true});  // يضيف ويتخطّى المتعارض
// → {ok, value: {added, skipped}}
```

**يستبدل افتراضياً.** دمج مجموعتَي سجلات دون أن يُقال لك كيف يُحلّ التعارض
طريقٌ إلى اختراع مجموعة ثالثة؛ فالمتعارض **يُبقي المخزَّن ويُعَدّ** لا يُخمَّن
فيه. ولا يُستبدل إلا ما ورد في الملف: استيرادٌ يحمل `safi` وحدها لا يمسّ
الطلبات.

**والتواريخ تعود كما كانت.** كان `addOrder` يختم كل طلب بلحظة كتابته — وهو
صحيح لطلب جديد، خاطئ لطلب مُستعاد: استيراد نسخة احتياطية عمرها سنة كان
يُعيد تأريخ طلباتها كلها إلى اليوم، بصمت، وهو يسمّي نفسه نسخة احتياطية.
كشفه اختبار ذهاب وعودة. والتاريخ غير القابل للقراءة **يُستبدل ولا يُصدَّق**،
لأن التخزين قابل للكتابة من المستخدم.

**والاستيراد دفعة واحدة.** كان يستدعي `addHolding` لكل سجل، وكلٌّ منها يقرأ
القائمة كاملة ويكتبها ويُعيد رسم الشاشات — فينمو العمل بمربّع حجم النسخة.
صار يبني القائمة في الذاكرة ويكتب مرّة واحدة: **٢٠٠ سجل في ١٤ جزءاً من
الألف من الثانية**، بعد أن كان ٤٠ سجلاً يكلّف ٩٨.

## الأحداث

```js
function onChange(e) { console.log(e.unit, e.at); }   // safi · delivery · all
Nokhatha.on(onChange);
Nokhatha.off(onChange);
```

يُطلَق بعد كل كتابة ناجحة، بعد أن تُحدَّث الشاشات. ومستمعٌ يرمي خطأً لا يمنع
البقيّة.

> تغيير من **نافذة أخرى** لا يمرّ بهذه المستمعين — النوخذة تلتقطه بحدث
> `storage` وتُعيد الرسم. أنصت لـ`window.onstorage` إن أردت ذلك أيضاً.

## مثال كامل

```js
const r = Nokhatha.addHolding({ticker: "NBK", qty: 250, cost: 900, price: 980});
if (!r.ok) { console.error(r.error); return; }

const t = Nokhatha.totals();
console.log(`القيمة السوقية ${t.portfolio.value.toFixed(3)} د.ك`);
console.log(`الربح ${t.portfolio.pl.toFixed(3)} (${t.portfolio.pct.toFixed(1)}%)`);
```

## ما لا تفعله هذه الواجهة

- **لا تفتح خادماً** ولا ترسل شيئاً إلى الشبكة. سياسة المحتوى `default-src
  'none'` تمنع ذلك أصلاً.
- **لا تُرجع HTML** ولا نصّاً منسّقاً. تُرجع بيانات؛ والهروب من المحارف شأن
  الجهة التي تعرضها.
- **لا تنشئ مفاتيح تخزين جديدة.** الأربعة نفسها التي تستعملها الشاشات.

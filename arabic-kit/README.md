# arabic-kit — حزمة اللغة العربية لمشروع موصول

حزمة صغيرة بلا اعتماديات تعالج ما تُخطئ فيه الواجهات العربية عادةً: **تمييز
العدد**. العربية لها ست صيغ لا صيغتان، فالكود الذي يكتب `${n} دقيقة` ينتج
«٥ دقيقة» و«٢ دقيقة» و«٠ دقيقة» — وكلها خطأ.

```bash
npm install ../arabic-kit      # داخل مشروع يستهلكها
npm test                       # ٢٤ اختبارًا
npm run sync                   # ينسخ الحزمة لنسختَي المتصفح
```

```js
const ar = require('arabic-kit');          // Node
// <script src="vendor/arabic-kit.js">     ← المتصفح، ثم window.arabicKit
```

## تمييز العدد

القاعدة التي تطبّقها الحزمة (فئات CLDR للعربية):

| العدد | الفئة | المثال | الصيغة النحوية |
|---|---|---|---|
| ٠ | `zero` | لا طلبات | نفي بالجمع |
| ١ | `one` | طلب واحد | مفرد |
| ٢ | `two` | طلبان | مثنّى |
| ٣–١٠ | `few` | ٥ طلبات | جمع (مضاف إليه مجرور) |
| ١١–٩٩ | `many` | ١١ طلبًا | مفرد منصوب بتنوين الفتح |
| ١٠٠+ | `other` | ١٠٠ طلب | مفرد مجرور |

الفئة تُحسب من **باقي القسمة على ١٠٠**، فـ«١٠٣» جمعٌ مثل «٣»، و«١١١» مثل «١١».

```js
ar.plural(0,  'order')   // لا طلبات
ar.plural(1,  'order')   // طلب واحد
ar.plural(2,  'order')   // طلبان
ar.plural(5,  'minute')  // ٥ دقائق      ← وليس «٥ دقيقة»
ar.plural(11, 'order')   // ١١ طلبًا
ar.plural(24, 'hour')    // ٢٤ ساعة
```

### المثنّى يتغيّر بالإعراب

بعد حرف الجر يُجرّ المثنّى: **قبل دقيقتين** لا «قبل دقيقتان».

```js
ar.plural(2, 'minute')                      // دقيقتان   (مرفوع)
ar.plural(2, 'minute', { case: 'oblique' }) // دقيقتين   (مجرور)
```

`ar.since()` يستعمل المجرور تلقائيًا لأنه يسبقه «قبل» أو «بعد».

### الصفة توافق الاسم

جمع **غير العاقل** يوصف بمفرد مؤنث، وجمع **العاقل** يوصف بجمعه — لذا يحمل كل
اسم في القاموس `gender` و`human`:

```js
ar.describe(5, 'order', 'active')  // ٥ طلبات نشطة      ← غير عاقل
ar.describe(5, 'agent', 'shown')   // ٥ مندوبين ظاهرين  ← عاقل
ar.describe(0, 'agent', 'shown')   // لا مندوبين ظاهرين
ar.describe(2, 'order', 'active')  // طلبان نشطان
```

### توسيع القاموس

```js
ar.noun('parcel', {
  gender: 'm', human: false,
  zero: 'لا طرود', one: 'طرد واحد', two: 'طردان', twoOblique: 'طردين',
  few: 'طرود', many: 'طردًا', other: 'طرد',
});
ar.adjective('late', { m: { one: 'متأخر', /* … */ }, pm: 'متأخرين', nh: 'متأخرة' });
```

اسم غير معروف يرمي خطأً واضحًا بدل إخراج نص مكسور بصمت.

## الأرقام والعملة

```js
ar.digits(2026)        // ٢٠٢٦
ar.number(128000)      // ١٢٨٬٠٠٠        فاصل الآلاف العربي U+066C
ar.number(1.5, 3)      // ١٫٥٠٠          الفاصلة العشرية العربية U+066B
ar.money(2.25)         // ٢٫٢٥٠ د.ك      الدينار الكويتي ثلاث خانات دائمًا
ar.percent(98)         // ٩٨٪
ar.toLatin('١٢٨٬٠٠٠')  // 128000         لقراءة مدخلات المستخدم
```

## الوقت والتاريخ

```js
ar.time(d)      // ٠٩:٤٢ صباحًا
ar.date(d)      // ١٢ أغسطس ٢٠٢٦
ar.date(d,true) // الأربعاء، ١٢ أغسطس ٢٠٢٦
ar.since(iso)   // قبل ٥ دقائق · قبل دقيقتين · الآن · بعد ساعة واحدة
ar.duration(95) // ساعة واحدة و٣٥ دقيقة
```

## النصوص

```js
ar.list(['حولي','العاصمة','الجهراء'])  // حولي، العاصمة والجهراء
ar.ltr('+965 2222 0000')               // يمنع انقلاب علامة + في جملة عربية (U+200E)
ar.normalize('الأَحمدي')                // الاحمدي — للبحث لا للعرض
ar.looseEqual('الفروانيّة','الفروانيه') // true
```

## النسخ في المتصفح

المشروعان يعملان **بلا خطوة بناء**، فتُنسخ الحزمة نسخًا مباشرًا إلى:

- `agent-system/public/vendor/arabic-kit.js` — يتم تلقائيًا عند `npm install` عبر `postinstall`
- `website/assets/js/arabic-kit.js`

`npm run sync` يحدّث النسختين، و`npm test` **يفشل** إذا انحرفت أي نسخة عن
الأصل — فلا يمكن أن تتقادم إحداها بصمت.

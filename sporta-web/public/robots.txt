# Sporta — crawler policy. All search + AI engines welcome on the storefront.
#
# NOTE ON STRUCTURE: a crawler obeys ONE group — the one matching its own name,
# or the wildcard group if no name matches. It does not read the wildcard group
# as well. So the Disallow lines have to be repeated in EVERY group. They were
# previously only in the wildcard group, which meant every named AI bot below
# was told "Allow: /" and nothing else, and was free to crawl /backends and the
# payment endpoints. Add a bot, add its Disallow/Allow lines with it.
#
# /api/ is closed except api.php itself: Googlebot renders the shop with
# JavaScript and must be able to fetch the product JSON and the slide/brand
# images it serves, or every product page renders empty for the crawler.

User-agent: *
Allow: /
Disallow: /backends
Disallow: /knet/
Disallow: /pay/
Disallow: /api/
Allow: /api/api.php

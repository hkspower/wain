# NOTE ON STRUCTURE: a crawler obeys ONE group — the one matching its own name,
# or the wildcard group if no name matches. It does not read the wildcard group
# as well. So the Disallow lines have to be repeated in EVERY group. They were
# previously only in the wildcard group, which meant every named AI bot below
# was told "Allow: /" and nothing else, and was free to crawl /admin and the
# payment endpoints. Add a bot, add its three Disallow lines with it.
